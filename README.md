# Red Music READY 3.2

Запуск:
1. Откройте PowerShell в папке проекта.
2. `npm.cmd install`
3. `npm.cmd start`
4. Откройте http://localhost:3000

Добавлено:
- полноценный экран входа/регистрации;
- регистрация с логином, паролем и отображаемым именем;
- уникальный ID каждому аккаунту;
- ID, логин и роль в профиле;
- выход из аккаунта возвращает на экран входа;
- данные пользователей и сессия сохраняются в localStorage;
- админ-панель показывает зарегистрированных пользователей;
- существующие промокоды, VIP, логи, статистика, поддержка и UI сохранены.

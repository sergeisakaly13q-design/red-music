# Red Music Security Final Security Monitoring

Добавлены финальные серверные механизмы мониторинга:

1. Security event logging
   - API 401/429 события;
   - IP, user ID, endpoint, method, status;
   - отдельная таблица `security_events`;
   - автоматическая очистка старых событий.

2. Attack/anomaly detection
   - обнаружение повторяющихся отказов авторизации и rate-limit событий;
   - окно анализа 10 минут;
   - события доступны OWNER через `/api/logs/security`.

3. Automatic temporary IP blocking
   - после 10 защищённых API нарушений за 10 минут IP временно блокируется;
   - длительность увеличивается ступенчато до 60 минут;
   - блокировка хранится в SQLite и переживает перезапуск;
   - OWNER/обычные пользователи не блокируются по роли, блокируется сетевой IP.

Важно: сетевой DDoS нельзя полноценно остановить кодом Node.js. Для него нужен инфраструктурный слой (например, бесплатный Cloudflare перед Render). Это отдельная настройка DNS/прокси и не добавляется как серверный middleware.

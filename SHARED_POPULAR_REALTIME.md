# Red Music: общие «Самые прослушиваемые треки»

Теперь счётчик прослушиваний хранится на сервере в SQLite-таблице `track_play_counts`, а не в `localStorage` браузера.

- Все пользователи видят один общий рейтинг.
- После запуска трека сервер увеличивает общий `play_count`.
- Главная автоматически обновляет рейтинг каждые 5 секунд, пока открыта.
- При возврате приложения на экран рейтинг обновляется сразу.
- Для запрета старых HTTP-кэшей API `/api/popular` отдаёт `Cache-Control: no-store`.

## Важный момент про Render Free

Сам код не очищает `track_play_counts` при обычном запуске или перезапуске Node.js. Но бесплатный Render использует эфемерную файловую систему. При полном redeploy/пересоздании инстанса SQLite-файл может быть потерян.

Поэтому для гарантированного сохранения статистики между деплоями нужен внешний persistent storage/database. Это не исправляется одним JavaScript-файлом и не должно маскироваться под «готовую вечную базу».

Текущая реализация уже готова для общего real-time рейтинга; существующая SQLite-база остаётся источником данных.

# Red Music — загрузка нескольких треков

Доработана загрузка локальной музыки:
- обычный выбор файлов теперь поддерживает `multiple`;
- можно выбрать сразу много аудиофайлов;
- добавлен отдельный выбор целой папки через `webkitdirectory` + `directory`;
- JavaScript получает `e.target.files`/`FileList` и обрабатывает все файлы циклом;
- повторный выбор того же файла разрешён после сброса input;
- фильтруются аудиоформаты MP3, WAV, OGG, M4A, FLAC, AAC и OPUS;
- существующая одиночная функция добавления переиспользуется, если она есть в проекте.
